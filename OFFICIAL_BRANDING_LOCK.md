# DCX Online Store — Official Branding Lock

The official branding source for this project is:

`assets/icon/app_icon.png`

This file is the user-supplied DCX Online Store app icon and app logo. It must remain the single source of truth for visual branding.

## Rules

- Do not regenerate or redesign the logo.
- Do not recolor it.
- Do not crop or stretch it.
- Do not replace it with a text-built logo, placeholder, downloaded image, or generated icon.
- Render the source asset with `BoxFit.contain` when used inside the Flutter UI.
- Keep `assets/icon/app_icon.png` registered in `pubspec.yaml`.
- Keep launcher icon generation pointed at the same source asset unless the user explicitly requests a branding change.

The logo may only be changed when the user explicitly requests it or deliberately replaces the source file.
