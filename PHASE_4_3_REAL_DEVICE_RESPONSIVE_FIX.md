# DCX Shop Phase 4.3 — Real Device Responsive Fix

## What was fixed

- Onboarding pages now scroll safely on short real-device screens.
- Illustration and typography automatically compact when vertical space is limited.
- Global app scrolling uses smooth bouncing + always-scrollable physics.
- Keyboard drag dismiss is supported on scrollable authentication content.
- Existing animated bottom navigation is preserved.
- A clean AndroidManifest template is included without `${applicationName}`.

## Repair the native Android folder safely

The Flutter source ZIP intentionally keeps platform code portable. On your PC, from the project root:

```powershell
Remove-Item -Recurse -Force android
flutter create --platforms=android .
```

Then replace only:

`android/app/src/main/AndroidManifest.xml`

with:

`platform_templates/android/AndroidManifest.xml`

Do NOT replace the generated Gradle files.

### MainActivity

Keep the `MainActivity.kt` generated by your own `flutter create` command because its package declaration matches your project namespace. It should extend `FlutterActivity`.

## Validation

```powershell
flutter clean
flutter pub get
dart format lib
flutter analyze
flutter build apk --debug
```

Then connect a real Android device and run:

```powershell
flutter devices
flutter run -d <YOUR_DEVICE_ID>
```
